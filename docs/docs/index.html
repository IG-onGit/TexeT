General

TexeT is a Python command-line application that gives you voice, AI and translation inside any editable text area. You start it once in a terminal, and it listens for keyboard shortcuts system-wide.

It works by copying your selection, processing it, and pasting the result back, so you never leave the app you are typing in.

Why TexeT

  • Works in your own apps. It uses copy and paste, so any field where you can select and paste text works.
  • Voice in and out. Dictate text or code, and have selected text read aloud.
  • Translation by suffix. Add /en to your text and press a shortcut.
  • AI is optional. Fixing, code writing, versions and replies use your own OpenAI API key.
  • Free and open source. MIT licensed, installed with one pip command.

Next: follow Installation, then learn the keyboard shortcuts.

How it works

How it works

When you run texet start, TexeT registers its keyboard shortcuts. Each shortcut runs one task:

  1. You press a shortcut.
  2. TexeT copies your selected text, or listens to your voice for the dictation shortcuts.
  3. It translates the text, reads it aloud, or sends it to OpenAI, depending on the shortcut.
  4. It pastes the result into the editable zone. Replies are copied to the clipboard instead.
  5. It plays a done or error sound when the task finishes.
texet start -> shortcuts registered

shortcut pressed
  |-- copy selection  (or listen to your voice)
  |-- translate | read aloud | OpenAI | parse
  '-- paste result   (or copy it to the clipboard)

Reading aloud runs in its own process, which is why you can stop it or start a new reading at any time.

GeneralInstallation

Installation

TexeT is published as a Python package.

  1. Open CMD (or your terminal) and run the install command.
  2. Restart your CMD.
  3. Run texet to check that it is installed. It lists the available commands.
pip install texet
texet

Start TexeT

texet aikey   # optional: needed for the AI shortcuts
texet start

Keep the terminal window open while you use TexeT. Press Ctrl+C there to shut it down.

ConfigurationKeyboard shortcuts

Keyboard shortcuts

Start TexeT with texet start, then use these shortcuts in any editable text area.

ShortcutAction
Ctrl + Alt + TTranslate the selected editable text. Add a language code such as /en to the end first.
Ctrl + Alt + RRead the selected text aloud.
Ctrl + Shift + Alt + RStop reading the selected text aloud.
Ctrl + Alt + WListen and write the text in the editable zone.
Ctrl + Shift + Alt + WListen and write grammar-corrected text. Needs an OpenAI key.
Ctrl + Alt + PParse the selected text for unusual characters.
Ctrl + Alt + CListen and write the code in the editable zone. Needs an OpenAI key.
Ctrl + Alt + FFix the selected text with grammar. Needs an OpenAI key.
Ctrl + Shift + Alt + FFix the selected code. Start comments with >> to base the fix on them. Needs an OpenAI key.
Ctrl + Alt + VAdd versions of the selected content. Needs an OpenAI key.
Ctrl + Alt + AGenerate a reply to the selected message, then press Ctrl+V to paste it. Needs an OpenAI key.
Ctrl + CShut the TexeT system down (in the terminal where it runs).

Fixing code with comments

If the selected code contains comments that begin with >>, TexeT implements the logic they describe and removes those comments. Without them, you say aloud what needs to be fixed.

def total(items):
    # >> return the sum of the prices
    pass
CommandsTranslating text

Translating text

TexeT reads the language from the end of your text. Write your text, add a slash and a language code, select everything, and press Ctrl + Alt + T. The translation replaces the selection.

Hola, ¿cómo estás?/en

If the code is missing or unknown, TexeT asks you to specify a language by adding something like /en to the end of the text.

System requirements

To run TexeT

  • Python 3 with pip
  • A keyboard, and a microphone for the dictation shortcuts
  • An OpenAI API key for the AI shortcuts
  • An internet connection for translation and AI requests
