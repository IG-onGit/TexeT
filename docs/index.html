Write, fix and translate text anywhere with one shortcut

TexeT is a Python command-line tool that adds voice, AI and translation to any editable text area. Select text or speak, press a shortcut, and the result is pasted for you.

Features

Eleven shortcuts for the text you write every day

Reading, writing, translating and fixing text are one key combination away. The AI shortcuts use your own OpenAI API key.

Translate in place

Add a language code such as /en to the end of your text and press Ctrl+Alt+T. The translation replaces it, with 100+ language codes supported.

Read text aloud

Select text and press Ctrl+Alt+R to hear it. Stop the reading or start a new one whenever you need.

Dictate anywhere

Press Ctrl+Alt+W and speak. TexeT types your words into the editable field, or fixes the grammar first with the Shift variant.

Fix text and code

Fix the grammar of selected text, or select code and say what to change. Leave >> comments in code and TexeT implements them.

Write code by voice

Describe the function you need, and TexeT writes the code and pastes it into your editor.

Replies, versions, clean-up

Generate a reply to a message, add up to four more versions of your text, or swap unusual characters for plain ones.

How it works

Start it once, then use it everywhere

TexeT runs in a terminal window and listens for its shortcuts in the background.

  1. Install and start

    Run pip install texet, then texet start. TexeT binds its keyboard shortcuts.

  2. Select text or speak

    Highlight text in any editable field, or press a dictation shortcut and talk.

  3. Get the result

    TexeT pastes the result in place. Replies are copied to your clipboard, so you press Ctrl+V.

Usage

Three commands to get going

Add your OpenAI key if you want the AI shortcuts, start TexeT, and press the shortcuts in any app.

  • Translate by adding /en to the end of your text
  • Dictate or write code by voice
  • Press Ctrl+C in the terminal to shut TexeT down

FAQ

Questions before you install

Is TexeT free?

Yes. TexeT is open source under the MIT License, so you can use, copy and modify it for free. The AI shortcuts send requests to OpenAI with your own API key, and OpenAI bills that usage under its own terms.

Do I need an OpenAI API key?

Only for the AI shortcuts: fixing text and code, grammar-corrected dictation, writing code, adding versions and generating replies. Translating, reading aloud, dictating and parsing unusual characters work without a key.

Where is my API key stored?

When you run texet aikey, TexeT writes the key to a file in a .texet folder inside your home directory. Run texet aikey -r to remove it.

Which apps and systems does it work with?

TexeT is a Python command-line app marked as OS independent. It copies your selection and pastes the result with keyboard shortcuts, so it works wherever you can select and paste text.

Add TexeT to your keyboard

Install it with pip, run texet start, and your shortcuts are ready.
